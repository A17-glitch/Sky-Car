# Sky Car

A small Flappy Bird style game. You fly an electric car through green pipes.
Made for fun with HTML and JavaScript.

## How to play
- Tap, click, or press Space to fly up.
- Avoid the pipes, the ground, and the top of the screen.
- Pass close to a pipe to see "CLOSE ONE!"

## Run it
Open `index.html` in your browser. No install needed.

## Change the difficulty
In `index.html`, change `GAP` (space between pipes) and `SPEED` (pipe speed).
